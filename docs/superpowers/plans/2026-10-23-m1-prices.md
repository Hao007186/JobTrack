# M1 查價功能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal：** 實作 PriceProvider（mock、SerpApi）、每日查價指令與額度預算、價格快照與基準、`/prices` 與 `/baseline` API，以及示範帳號的價格資料。

**Architecture：** 新增 `modules/prices`。`providers/` 是不碰 DB 的查價來源；`budget.py`、`baseline.py` 是純規則；`checker.py` 負責「找出要查的 query → 搶下 → 呼叫 provider → 記錄」，每個 query 各自 commit；`router.py` 提供讀取 API。測試用假的 provider 與 `httpx.MockTransport`，完全不連網路。

**Tech Stack：** 既有的 FastAPI、SQLAlchemy 2.0 async、Alembic、pytest；`httpx`（從 dev 相依移到正式相依）。

**Spec：** [docs/superpowers/specs/2026-10-23-m1-prices-design.md](../specs/2026-10-23-m1-prices-design.md)

## Global Constraints
- 「今天」「今天 00:00」「本月」一律以台灣時間（`app.core.clock.TAIPEI_TZ`）計算
- 價格一律 TWD 整數；快照 `provider` 為 `serpapi` 或 `mock`
- 預算 `ceil(remaining / 本月剩餘天數（含今天）)`；`MAX_CONSECUTIVE_FAILURES = 3`；SerpApi 逾時 60 秒
- SerpApi 參數：`engine=google_flights`、`type`（來回 1、單程 2）、`travel_class`（economy 1、premium_economy 2、business 3、first 4）、`currency=TWD`、`hl=zh-TW`、`gl=tw`；`return_date` 只有來回才帶；`include_airlines` 有指定才帶（逗號分隔）
- API key 不得出現在任何錯誤訊息、log、測試資料、commit 中；錯誤訊息把 key 換成 `***`；`httpx` logger 設為 WARNING
- key 只放在 `backend/.env`（不進 Git）；執行錄製腳本時**不得把 key 寫在指令列**
- 測試不連網路、不花額度
- 指令在 `backend/` 下執行；ruff、mypy strict 通過；Commit 用 Conventional Commits、繁體中文，結尾 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`
- 寫檔用編輯工具，不用 bash heredoc

## Review Focus
1. **SerpApi 的航班選項缺少 `price`**（Google 偶爾回傳沒有價格的選項）：應略過那筆；全部都沒有價格時視為查無航班 → Task 2 測試
2. **`price_insights` 不完整**（`typical_price_range` 缺少或只有一個值、`price_history` 是空陣列）：不應拋例外，insights 視為 None 或 `history_low` 為 None → Task 2 測試
3. **HTTP 錯誤的例外訊息含完整網址**（httpx 的 `HTTPStatusError` 會帶 URL，裡面有 `api_key`）：`ProviderError` 訊息必須已遮掉 → Task 2 測試
4. **台灣時間的「今天已查」邊界**：`last_checked_at` 為台灣時間昨天 23:50（UTC 15:50）時，今天 00:30 執行仍要查；為今天 00:10 則不查 → Task 4 測試
5. **`api_usage` 的月份以台灣時間計**：台灣時間 11/1 00:10（UTC 10/31 16:10）的呼叫算在 `2026-11` → Task 4 測試
