# 階段 1：需求分析（Requirements）

[← 回總覽](architecture.md)｜下一階段：[系統設計](02-design.md)

## 已確定的決策
| 項目 | 決定 | 理由 |
|---|---|---|
| 價格來源 | **只用 API，不寫爬蟲**：SerpApi Google Flights（250 次／月免費、即時） | Travelpayouts 在 M0 實測，台灣出發的固定日期查詢只有 10% 有資料、來回票完全沒有，不採用；Skyscanner 只開放商業合作夥伴且禁止快取；Amadeus Self-Service 已在 2026/7 關閉；自己寫爬蟲違反條款且會被封鎖。SerpApi 本身也有供應風險，用 `PriceProvider` 介面隔離 |
| 額度策略 | 每天依剩餘額度分配預算，各 query 輪流用 SerpApi 查價；**嚴格限制在免費額度內**，用完就暫停查價，不升級付費方案 | 見[階段 2〈額度策略〉](02-design.md#額度策略) |
| 航空公司 | 使用者可勾選，不勾就是全部 | SerpApi `include_airlines` 篩選 |
| 追蹤條件 v1 | 台灣出發、單程或來回、**固定日期** + **目標價（必填）**，幣別一律 TWD | 日期區間會讓 API 用量倍增，列為擴充；目標價不需要歷史資料，確保最基本的通知永遠有效 |
| 通知規則 | **狀態變化才通知**，不是條件成立就一直通知 | 避免價格持續低於目標價時天天被打擾，見[階段 2〈觸發與去重〉](02-design.md#觸發與去重狀態變化才通知) |
| 帳號 | **網站自有帳號**：Email + 密碼，**直接註冊即可使用**（不做 Email 驗證）；另提供唯讀**示範帳號** | LINE 是可選的綁定項目；示範帳號讓面試官免註冊即可瀏覽；取消驗證的理由見[總覽〈2026-10-23 決策紀錄〉](architecture.md#2026-10-23-決策紀錄) |
| 追蹤上限 | 每人最多 **3 個**追蹤（active + 排隊中）；全站最多 **8 個** active price_query，額滿時新追蹤進入**排隊中**（暫不查價），有空位再依序啟用 | 公開註冊下保護 250 次／月的額度，見[階段 2〈額度策略〉](02-design.md#額度策略)的用量估算；8 個 query 剛好每個每天查一次，準確度和即時性優先於使用人數；排隊讓晚註冊的人仍能建立追蹤 |
| 通知管道 | 站內通知中心 + Email 一律提供；有綁 LINE 就額外推播 | LINE Notify 已在 2025/3 停止服務，改用 Messaging API |
| 網域與 Email | 購買自有網域（約 US$10／年），DNS 放 Cloudflare；寄信服務用 **Resend**（走 SMTP，從自有網域寄） | 自訂網址讓作品集更完整；Resend 免費額度足夠，也不需要 AWS 帳號；走 SMTP 之後換服務只改設定 |
| 查價頻率 | 排程每天執行一次；每個 query 多久查到一次，取決於全站 active query 數 | 每月 250 次約等於每天 8 次，見[額度策略](02-design.md#額度策略)的用量估算 |
| 交付範圍 | 分 4 個里程碑：M1 MVP 上線 → M2 LINE → M3 k8s/E2E → M4 維運強化 | 先有可展示的成果，再逐步擴充 |

## 驗收條件（範例）
- US-06（目標價 10,000）：
  - checker 確認價格 9,500 → 5 分鐘內產生 1 筆 alert，站內通知和 Email 各送出 1 次
  - 下次確認價格 9,300（比 9,500 只降 2%，即使是歷史新低）→ 不通知
  - 下次確認價格 8,900（比上次通知的 9,500 降 ≥5%）→ 再通知 1 次
  - 價格回升到 10,500，之後又跌到 9,800 → 視為重新跌破目標價，再通知 1 次
- US-07：綁定時 `state` 遭竄改 → 拒絕綁定；一個 LINE 帳號只能綁一個會員；使用者封鎖官方帳號 → 停止 LINE 推播並產生一則系統通知
- US-01：註冊後立即登入；同一個 Email（不分大小寫）不能重複註冊；連續登入失敗 5 次鎖定 15 分鐘
- US-02：已有 3 個追蹤（active + 排隊中）時再新增 → 拒絕並提示；全站 active price_query 已達 8 個且新追蹤需要建立新 query → 追蹤建立成功但狀態為「排隊中，暫不查價」；名額空出時立刻依建立時間依序啟用，並發一則系統通知
- US-11：示範帳號除了登出和 refresh token 以外，所有寫入操作回 403；示範帳號的追蹤不會被 checker 查價、不消耗任何 API 額度

## 非功能需求
| 類別 | 需求 |
|---|---|
| 成本 | 網域約 US$10／年；AWS 每月約 US$0（免費方案結束後 ECR、S3 每月幾分錢）；Email 用 Resend 免費方案；所有外部 API 用免費方案 |
| 額度 | SerpApi ≤ 250 次／月（硬上限）；LINE ≤ 200 則／月 |
| 效能 | API p95 < 500ms（Lambda、Neon 冷啟動除外）；從確認降價到發出通知 < 5 分鐘 |
| 可靠性 | 通知不漏發（SQS 重試 + DLQ）、不重發（冪等鍵） |
| 安全 | Argon2 密碼雜湊、HttpOnly Cookie、LINE webhook 簽章驗證、CloudFront 來源驗證標頭、機密資料不進 Git、使用者之間資料隔離 |
| 可維護性 | 單人可維護；全部 AWS 與 Cloudflare 資源用 Terraform 管理 |
| 規模 | 使用者是本人和極少數人；≤ 8 個不同查詢組合（由〈已確定的決策〉的追蹤上限強制）。**準確度和即時性優先於使用人數** |
